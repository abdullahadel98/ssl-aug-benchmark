================================================================================
                      CONFIGURATION PARAMETERS
================================================================================

In learning/solo-learn/scripts/pretrain/cifar/simclr_styletrans.yaml:

batch_augmentations:
  style_transfer:
    enabled: true
    
    # Path to pre-extracted style features
    features_path: "$HOME/.../style_feats_adain_1000.npy"
    
    # Paths to pretrained AdaIN models
    encoder_path: "$HOME/.../vgg_normalised.pth"
    decoder_path: "$HOME/.../decoder.pth"
    
    # Blending strength [0, 1]
    alpha_min: 0.7      # Minimum
    alpha_max: 1.0      # Maximum
    
    # Probability of applying augmentation [0, 1]
    probability: 0.1    # 10% of samples

Parameter Meanings:
- alpha_min/alpha_max: Controls style transfer strength (0=content, 1=full style)
- probability: Chance to apply augmentation per sample (0=never, 1=always)
- features_path: numpy array of style features [N_styles, feature_dim]
- encoder_path: VGG encoder weights for feature extraction
- decoder_path: AdaIN decoder weights for style application

================================================================================
                      TROUBLESHOOTING QUICK GUIDE
================================================================================

ISSUE: Test fails with import error
SOLUTION: Check PyTorch is installed
  $ python -c "import torch; print(torch.__version__)"

ISSUE: "FileNotFoundError" for style features
SOLUTION: Verify path exists, use absolute paths or $HOME
  features_path: "${HOME}/augmentation/.../style_feats.npy"

ISSUE: "CUDA out of memory"
SOLUTION: Reduce batch size or image resolution
  Temporarily: test_style_transfer.py automatically uses small batches

ISSUE: "Transform not initialized"
SOLUTION: Check all dependencies installed
  $ conda run -n sololearn python test_style_transfer.py

ISSUE: Style transfer not visible
SOLUTION: Check alpha and probability parameters
  alpha_min >= 0.7, probability >= 0.1

ISSUE: "Device mismatch" error
SOLUTION: Already fixed in updated test script
  No action needed, just run test_style_transfer.py
